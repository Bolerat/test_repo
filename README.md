# 同窝 Covey · 宠物日常

围绕"人和宠物一起生活的日常"的移动端 Web 应用：记录顺手、照护安心、AI 在合适的时候帮一步。纯前端实现（HTML/CSS/JS，无构建、无第三方依赖），数据保存在本机浏览器 localStorage。

## 运行

```bash
python3 -m http.server 8000
# 打开 http://localhost:8000
```

或直接用任意静态服务器托管整个目录。建议移动端浏览器或浏览器设备模拟查看。

## 功能

| 页面 | 内容 |
| --- | --- |
| 今日 | 照护清单（按物种自动生成：猫含清理猫砂、狗含遛弯）、一键完成/撤销、连续照顾天数、近 7 天完成率、待办提醒、Pawly 观察、最新记录、拍照/记一笔/AI 建议快捷入口 |
| 记录 | 时间线手账，按天分组；筛选（照片/花费/照护/健康/日常）与搜索；照片点击放大；记录可删除 |
| AI 助手 | 对话式助手 Pawly，基于宠物档案、近 14 天照护记录、最近条目、体重与提醒生成上下文；快捷提问；需在「我的」中配置 API |
| 宠物 | 档案编辑（名字/物种/品种/生日/体重）、体重记录、家庭成员（本机演示，多人实时同步为后续能力） |
| 我的 | **AI API 配置**（OpenAI 兼容：服务商预设 / 地址 / Key / 模型，支持测试连接）、数据导出/导入/清空 |

## AI 配置

在「我的 → AI 助手设置」填入：

- 服务商：DeepSeek / OpenAI / 智谱 GLM / 通义千问 / 自定义（均为 OpenAI 兼容 chat/completions 接口）
- API 地址、API Key、模型

配置仅保存在本机浏览器。浏览器直接跨域调用需要接口支持 CORS，否则请填入支持 CORS 的代理地址。「测试连接」会发一条最小请求验证。

## 数据

- 全部数据存于 `localStorage`（键 `covey-state-v1`），单设备单浏览器。
- 照片经 canvas 压缩（最长边 900px，JPEG）后以 dataURL 存储；记录上限 800 条。
- 「我的 → 数据」可导出 JSON 备份或导入恢复。

## 设计说明

UI 为本项目重新设计：暖纸色底 + 陶土橙主色，移动端优先单栏卡片布局，底部五栏导航。不依赖参考原型的视觉与代码结构。
